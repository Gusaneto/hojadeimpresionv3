IMPRESIÓN GUSANIZA — AJUSTE DE TAMAÑO

Cambios principales:
1. Todas las imágenes se colocan en marcos idénticos de 15.80 × 24.27 cm.
2. Se estiran al marco exacto aunque originalmente sean más grandes, pequeñas o tengan otra proporción.
3. Se detectan y normalizan márgenes exteriores casi blancos o transparentes para que el contenido útil no se vea más pequeño en una columna.
4. No se agregan franjas blancas dentro del marco; puede haber una ligera deformación para igualar medidas.
5. Base de impresión: 65 × 85 cm; salida JPG a 300 DPI.
6. Separación: 3 cm entre columnas y 8 cm entre filas.
7. Las guías punteadas solo aparecen en la vista previa, no en el JPG final.

SUBIR A VERCEL:
- Descomprime el ZIP.
- Importa la carpeta gusaniza_fix como proyecto en Vercel.
- No necesita Node.js, backend ni base de datos.
